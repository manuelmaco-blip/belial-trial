# Belial Trial

PWA di gestione combattimenti per Dungeon Master.

## File
- index.html
- style.css
- app.js
- manifest.json
- service-worker.js
- icons/

## Uso
Per far funzionare la modalità PWA servono `https` oppure `localhost`.

Esempio rapido in locale:
```bash
python3 -m http.server 8000
```

Poi apri:
`http://localhost:8000`

## Funzioni incluse
- più combattimenti
- salvataggio automatico
- preferiti
- alleato / nemico / PNG
- PF massimi e attuali
- ricerca
- annulla ultima modifica
- modifica rapida con pressione prolungata
- esporta / importa backup
- installazione come PWA
- funzionamento offline dopo il primo caricamento
